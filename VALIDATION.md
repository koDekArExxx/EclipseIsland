# Проверки 0.9.0

- Node: 169 тестов, все прошли. В том числе интерфейс, музыка, воспроизведение, запись/повтор, скрытие, файлы, автозагрузка и новая загрузка кодировщика.
- Python: 11 тестов бота, все прошли. Проверка подписки при каждой выдаче, отказ при ошибке проверки, запрет чужой админки, подтверждение выпуска один раз, отмена и наблюдение полного релиза.
- Bootstrapper.cs и LauncherTests.cs скомпилированы с ограничением C# 5 и reference assemblies .NET Framework 4.8. Тестовый загрузчик с иконкой: 103424 байт. Это тестовая сборка с примерным адресом, она не распространяется как рабочий Setup.
- Проверена реальная загрузка закреплённого FFmpeg b6.1.1: распакованный размер 82797568 байт, SHA-256 совпадает с build.json. Проверяются также повреждение gzip/хеша и повторная попытка.
- Статический preview пересобран.
- Полная сборка Electron, выполнение Windows-тестов загрузчика, установка/откат, системный захват и измерение плавности поверх игры в текущей Linux-среде не выполнялись. Windows-проверки загрузчика добавлены в release workflow перед публикацией.
- Публикация GitHub и запуск настоящего Telegram-бота не выполнены: требуются созданный владельцем репозиторий и секреты на его хосте. В архиве нет токенов.
