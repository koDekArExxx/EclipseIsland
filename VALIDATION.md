# Проверки 0.9.1

- 172 теста приложения прошли, включая паузу/продолжение тем же сочетанием, замену занятого загрузчика после разблокировки, проверку SHA-256 и сохранение старого EXE при ошибке.
- 12 тестов бота прошли; SQLite-соединения явно закрываются.
- Bootstrapper.cs и LauncherTests.cs скомпилированы как C# 5 с reference assemblies .NET Framework 4.8. Проверки палитры, режима загрузчика и некорректных настроек добавлены в Windows-тесты загрузчика.
- Setup собран под koDekArExxx/EclipseIsland; native runtime .NET в установщик не включён.
- В исходниках удалена временная подмена материала .is-morphing и перемещение блика вслед за курсором. Прозрачный материал остаётся белым/нейтральным; явно заданные расширенные цвета сохранены.
- Временные скачанные компоненты и node_modules в архив не включены.
- Запуск самого WinForms-интерфейса, DWM-скругления, реальная передача управления загрузчику на Windows и плавность поверх игры в текущей Linux-среде не проверены. Тесты файловых операций моделируют блокировку Windows; полный Windows build выполняется в Actions.
- Готовый Setup до публикации 0.9.1 получает текущий опубликованный выпуск из GitHub. Для новых функций самого островка нужно опубликовать новую сборку приложения.
