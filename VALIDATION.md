# Проверки 1.0.3

- 183 JavaScript-теста успешно, без пропусков; 12 Python-тестов бота успешно.
- Добавлены проверки сохранения DOM кнопок/обложки/фокуса при переходе между панелями и повторном клике, временного буфера без постоянного индекса, явной отправки canvas-кадров и отсутствия таймера метрик в повторе.
- Реальный браузерный smoke: тот же capture-worker.js получал движущийся синтетический canvas 960×540 / 60; изменение constraints отключено только у тестового источника, чтобы проверить путь resize. Выход: VP8/WebM 640×360, цель 30 FPS. Пауза и продолжение выполнены, worker завершился без ошибки. FFprobe декодировал 74 кадра за 2,5066 с учтённого времени записи, файл 64733 байта. Это не Windows desktop capture, не тест звука loopback и не оценка FPS в игре.
- Прогон компактного островка в покое, Chrome Headless/Linux, 3 секунды: исходный интерфейс — 4 постоянные анимации / 174 кадра screencast; новые «Баланс» и «Экономный» — 0 / 1. TaskDuration 7/10/14 мс; снижения CPU на этом коротком стенде не доказано. Результат подтверждает отсутствие постоянной отрисовки, а не выигрыш игрового FPS.
- Видео проверено по кадрам: переходы, режим нагрузки, профили записи, пауза и повтор, три разных цвета. Музыка синхронизирована с переключением/паузой и приглушена.
- Ручные проверки Windows, native input-region во время анимации, аппаратные кодировщики и игровой FPS остаются необходимыми перед массовым выпуском.

# Проверки 1.0.2

- 180 JavaScript-тестов: успешно, без пропусков.
- 12 Python-тестов бота: успешно.
- Проверены: автоматический и ручной битрейт; сохранение старого нестандартного битрейта; выбор энергоэффективного кодека и резервный путь; остановка во время медленной смены сегмента; ограничение canvas до выбранной частоты; сохранение режима нагрузки и профилей через настоящий UI.
- Небольшой сравнительный прогон: Chrome Headless 158, Linux, 1080×1080. Компактный островок с музыкой, курсор вне островка, запись/повтор выключены, после стабилизации интерфейса. За 3 секунды: до правок 4 активные анимации и 180 кадров compositor; «Баланс» и «Экономный»: 0 активных анимаций, 1 кадр. Счётчик CDP screencast фиксирует отправленные кадры, это не измерение FPS игры и не доказательство конкретного выигрыша CPU/GPU. TaskDuration: 7/18/13 мс соответственно; на этом коротком прогоне падение CPU не доказано.

- Ролик: 1080×1080, H.264/AAC, около 22 секунд. Данные демонстрационные, музыка тихая; кадры проверены.

# Проверки 1.0.1 Fix

- 172 JS-теста и 12 Python-тестов прошли.
- Загрузчик и его тестовая программа скомпилированы с C# 5 и минимальным набором reference assemblies .NET Framework 4.8, соответствующим Windows-скриптам сборки. Добавлена явная ссылка Accessibility.dll.

PNG содержимого публикуются как артефакт installer-ui-check. На неинтерактивном раннере открытие окна пропускается, проверки отрисовки отдельных кнопок остаются.
- Отрисовка всего окна и фактическое DWM-скругление в Linux-среде не запускались. PNG DrawToBitmap проверяют содержимое, но не являются снимками DWM-композиции с тенью.
