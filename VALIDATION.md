# Проверки 1.0.1 Fix

- 172 JS-теста и 12 Python-тестов прошли.
- Загрузчик и его тестовая программа скомпилированы с C# 5 и минимальным набором reference assemblies .NET Framework 4.8, соответствующим Windows-скриптам сборки. Добавлена явная ссылка Accessibility.dll.
- Windows-проверки теперь рисуют кнопки в обычном, наведённом и нажатом состояниях, проверяют видимость крестика и фон без системных квадратов, доступное нажатие и недоступность элементов.
- При наличии интерактивного рабочего стола Windows-проверки открывают загрузчик без сетевых запросов, проверяют native frame / client border и пропорции окна. PNG содержимого публикуются как артефакт installer-ui-check. На неинтерактивном раннере открытие окна пропускается, проверки отрисовки отдельных кнопок остаются.
- Отрисовка всего окна и фактическое DWM-скругление в Linux-среде не запускались. PNG DrawToBitmap проверяют содержимое, но не являются снимками DWM-композиции с тенью.
