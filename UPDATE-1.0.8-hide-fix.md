# EclipseIsland 1.0.8 — возврат после Ctrl + Alt + I

При возврате из ручного скрытия создаётся новое окно островка вместо повторного включения ввода на окне, которое игнорировало мышь. Возврат работает через Ctrl + Alt + I, меню трея и настройку включения. Музыка, запись, буфер повтора и остальные службы продолжают работать. Островок возвращается свёрнутым. Скрытие во время загрузки нового окна учитывается; поздний ready-to-show от старого окна не влияет на новое. Временное скрытие для снимков использует собственный жизненный цикл.

Версия сохранена: 1.0.8. Исправление package-lock.json (dotenv-expand 11.0.7) также включено.

## Исходники

Распакуйте поверх проекта с заменой файлов. Архив содержит накопленные изменения приложения, Windows Setup собирается на GitHub.

```powershell
git add .
git commit -m "Fix 1.0.8 island input after visibility toggle"
git pull --rebase origin main
git push origin main
```

## Перевыпуск того же 1.0.8

Старый Telegram-бот не принимает уже опубликованный номер. Бота этот архив не меняет.

1. После push откройте https://github.com/koDekArExxx/EclipseIsland/actions/workflows/release.yml
2. Run workflow → main → version: 1.0.8.
3. Включите `replace_existing` (Replace the existing release of this version).
4. Запустите и дождитесь успешного завершения.

Новый флажок по умолчанию выключен. Заменять разрешено последний опубликованный релиз либо оставшийся черновик. До успешного окончания тестов и сборки существующий выпуск не изменяется. При замене выпуск временно переводится в черновик, тег переводится на текущий коммит, файлы заменяются и выпуск публикуется снова. Если публикация прервётся, он останется черновиком; повторите с тем же флажком. Сам этот архив ничего не публикует.

Уже установленная старая 1.0.8 не получает такую замену автоматически: текущий загрузчик сравнивает номер версии. Просто повторный запуск Setup также пропустит имеющуюся 1.0.8. Для установки исправления: закройте островок через трей → удалите EclipseIsland через установленные приложения Windows → установите заново из нового Setup. Пользовательские настройки находятся отдельно в Roaming/EclipseIsland; штатный удалитель удаляет каталог установки в Local/EclipseIsland. Сохранённые скриншоты и записи в пользовательских папках не удаляются.

Пользователи предыдущих версий смогут получить 1.0.8 обычным обновлением после успешной публикации.

## Проверки

204 JS-теста прошли, ошибок и пропусков нет. Расширенная проверка главного процесса покрывает повторные циклы скрытия/возврата, быстрые переключения, скрытие до ready-to-show, поздний callback старого окна, отсутствие активации окна и сохранение работающих служб. YAML сборки разобран, флажок по умолчанию выключен и шаги тестов стоят до изменения выпуска.

Настоящие Windows HWND и ввод в играх здесь не проверялись. На Windows перед распространением проверьте 10 циклов Ctrl + Alt + I с кликами по островку после каждого возврата, в том числе во время записи и после обрезки снимка. Перевыпуск GitHub с новыми шагами здесь не запускался.
