# Ручная проверка на Windows

Этот список предназначен для проверки на целевом компьютере. В среде разработки Windows и игры недоступны; следующие пункты здесь не подтверждены.

1. `npm ci`, `npm start`: появились настройки и остров, значок в трее. Консоль не показывает необработанных ошибок.
2. Навести курсор, нажать на остров, переключить три вкладки, свернуть кнопкой и Esc. Пустая область вокруг острова пропускает клики на рабочий стол.
3. Поменять цвет, масштаб, секунды, отступ и экран. Закрыть приложение через трей, запустить снова: настройки сохранились.
4. Скрыть и показать остров через Ctrl + Alt + I. Раскрыть через Ctrl + Alt + Space. Если сочетание занято, на странице горячих клавиш появляется пояснение.
5. Найти город, выбрать его, дождаться температуры и ветра. Отключить интернет, обновить погоду: отображается ошибка, а не выдуманная температура. Включить интернет, повторить обновление.

### Курсор на скриншотах

- В разделе «Скриншоты» выключить «Показывать курсор мыши». Навести мышь на заметный участок и сделать снимок экрана (Ctrl+Alt+P), затем области (Ctrl+Alt+S). Указателя в сохранённых файлах быть не должно; на рабочем столе он остаётся видимым.
- Включить настройку, повторить оба снимка; указатель должен попасть в кадр, если находится в области захвата на момент заморозки изображения.
- Перезапустить приложение, проверить сохранение настройки. Повторить на мониторе с другим масштабом DPI и отрицательными координатами. Проверить PNG, JPEG, буфер обмена и отмену выделения.
