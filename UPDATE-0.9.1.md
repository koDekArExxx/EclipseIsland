# Как выпустить 0.9.1

## Изменения

- Ctrl + Alt + стрелка вниз переключает паузу и воспроизведение.
- При наведении, кликах, разворачивании и уведомлении о скриншоте выбранное стекло не заменяется плотным тёмным фоном. Убраны движущийся за курсором блик и изменение оттенка рамки при наведении в прозрачном режиме. По умолчанию прозрачное стекло нейтральное белое. Расширенные пользовательские цвета не сбрасываются.
- Setup и проверка обновлений получили интерфейс в стиле настроек: цвета из настроек приложения, фирменный знак, этапы, плавный прогресс, свои кнопки, поддержка масштаба Windows и reduced motion.
- Новый загрузчик включается в пакет приложения с SHA-256. При старте нового приложения постоянный загрузчик обновляется атомарно после освобождения EXE старым процессом. При сбое сохраняется старый загрузчик. Его новое оформление появится со следующего запуска. Само приложение ради этой замены не закрывается.

## Публикация

1. В VS Code открой свою существующую папку проекта с Git. Выполни `git pull --ff-only`, чтобы получить исправления, которые ты загружал через сайт GitHub.
2. Распакуй EclipseIsland-0.9.1-update.zip во временную папку. Скопируй её содержимое в корень проекта с заменой файлов. package.json должен находиться прямо в корне, не внутри второй папки.
3. Выполни:

```powershell
git add .
git commit -m "EclipseIsland 0.9.1: setup, glass and music shortcuts"
git push
```

4. GitHub → Actions → Publish EclipseIsland → Run workflow. Ветка main, версия **0.9.1**. Нужен новый запуск по main, не повтор старого коммита.
5. После успешной сборки в Releases появится 0.9.1. Бот автоматически возьмёт новый Setup из этого выпуска (кеш последнего выпуска обновляется в течение двух минут).

На Bothost код бота ради этого обновления менять не требуется.

Готовый EclipseIsland-Setup-0.9.1.exe можно запустить для проверки нового оформления загрузчика уже сейчас. Он обращается к текущему опубликованному выпуску GitHub: до публикации 0.9.1 установит/запустит имеющуюся 0.9.0. Не добавляй этот готовый EXE в Git — в релизе его соберёт Actions из исходников.

Проверены 172 JS-теста, 12 Python-тестов и компиляция C# загрузчика. Сам интерфейс Windows здесь не запускался.
