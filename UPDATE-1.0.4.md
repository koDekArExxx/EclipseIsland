# EclipseIsland 1.0.4

Исправлено восстановление ввода островка после встроенного просмотра записи.

- Просмотрщик видео восстанавливает область кликов островка после закрытия, сворачивания, выхода из полноэкранного режима и отмены разворачивания.
- Native-пропуск мыши явно сбрасывается, область окна применяется заново. Через короткую задержку выполняется повторное восстановление, когда Windows завершает переключение окон.
- Нет перезапуска приложения или пересоздания окна островка. Фокус у игры/приложения не запрашивается.
- Вручную скрытый островок остаётся скрытым; временное скрытие для скриншота не прерывается.
- При сбое процесса видеоплеера или ошибке загрузки окно закрывается с тем же восстановлением.
- Просмотр скриншотов использует общее восстановление ввода.

## Как установить исходники и выпустить

Распакуйте архив поверх папки проекта с заменой файлов. Архив включает правки 1.0.2 и 1.0.3, видео в нём нет. Windows EXE собирается при выпуске через бота.

В терминале VS Code из папки проекта:

```powershell
git add .
git commit -m "EclipseIsland 1.0.4"
git pull --rebase origin main
git push origin main
```

Затем в боте: Админка → Выпустить обновление → `1.0.4`.

## Проверки

184 JS-теста прошли. Дополнительно проверена связка callback просмотрщика → реальное восстановление основного окна: input-region применяется повторно, пропуск кликов сбрасывается, фокус не запрашивается. Проверены закрытие плеера, сворачивание, выход из fullscreen, сбой процесса, отложенное повторное восстановление, скрытый островок и временная приостановка для скриншота.

Поведение Windows HWND здесь проверено через модели событий Electron, не на реальном рабочем столе Windows. Перед массовым выпуском откройте записанное видео, включите/выключите fullscreen, закройте плеер и проверьте музыку, вкладки и кнопки островка. Повторите со скрытым Ctrl+Alt+I островком: самопроизвольного появления быть не должно.
