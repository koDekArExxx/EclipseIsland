# Обновление исходников до 1.0.0

Этот архив применяется поверх исходников 0.9.1. Готовый Setup соберёт GitHub Actions.

1. В терминале VS Code внутри своего проекта сначала выполни `git pull --rebase origin main`. Если есть CONFLICT — сначала закончи объединение, не используй force push.
2. Скопируй содержимое EclipseIsland-1.0.0-update.zip в корень проекта с заменой файлов. package.json должен лежать прямо в корне, а не во второй вложенной папке.
3. Выполни:

```powershell
git add .
git commit -m "EclipseIsland 1.0.0"
git push
```

4. GitHub → Actions → Publish EclipseIsland → Run workflow → main, версия **1.0.0**. Запускай новую сборку по текущей main.
5. После зелёной сборки выпуск появится в Releases. Бот получит новый Setup из этого выпуска; для кнопки «Выпустить обновление» можно указать 1.0.0 вместо ручного запуска Actions, если эта версия ещё не публиковалась.
6. Закрой старый островок через трей и снова запусти через установленный ярлык — загрузчик скачает новую версию.

На хостинг бота этот архив загружать не нужно. Код бота ради этих изменений не менялся.

Значок в трее стал основным цветным значком приложения. Окна и панель задач тоже получают многоразмерный ICO. Если закреплённый ярлык показывает старый кешированный значок, открепи его и закрепи заново после запуска 1.0.0.

Удалены только указанные элементы настроек; автоматическое подключение музыки и уведомления о загрузках на островке продолжают работать.
