# EclipseIsland 0.9.1

Плавающий островок для Windows 10/11: музыка, погода, запись экрана и мгновенный повтор, скриншоты, быстрый запуск, отображение файловых операций и загрузок. Настройки и оформление сохранены из версии 0.8.2.

**Начни с [START-HERE.md](START-HERE.md)**: пошаговая загрузка в GitHub, получение маленького Setup, запуск Telegram-бота и выпуск обновлений.

## Что изменилось

В 0.9.1 Setup и проверка обновлений оформлены как настройки: тёмная карточка, плавный прогресс, этапы и сохранённые цвета. Ctrl+Alt+Down переключает паузу/воспроизведение.

Удалён индикатор FPS и его постоянный цикл отрисовки. Объединены измерения границ во время анимаций. Выбранный материал сохраняется во время переходов; прозрачное стекло нейтральное, без подмены на плотный фон и бегающего блика. Реальная плавность под нагрузкой игры требует проверки на Windows.

Добавлен маленький установщик/загрузчик на .NET Framework: перед запуском проверяет публичный GitHub Release, скачивает пакет приложения, проверяет SHA-256 и устанавливает новую версию рядом с предыдущей. Автозагрузка и новые ярлыки ведут через него. При недоступной сети остаётся установленная копия. Старые NSIS/portable EXE эту схему не поддерживают.

FFmpeg загружается один раз при первом использовании MP4/повтора, поэтому web-пакет приложения не содержит ещё ~80 МБ кодировщика. Нативный медиасервис собирается в Actions из C#-исходников. В этом исходном архиве нет node_modules и готовых runtime-библиотек.

Telegram-бот выдаёт Setup после проверки подписки @EclipseIsland. Админ 1375098087 может запустить выпуск из текущей main, посмотреть состояние сборки и проверить настройку. Все токены задаются только в окружении сервера. Публичные файлы GitHub можно пересылать; проверка подписки действует на выдачу через бота.

## Разработка

Windows x64, Node.js 22.22.2+ ветки 22 и .NET 10 SDK:

```powershell
npm.cmd ci
npm.cmd run build:media
npm.cmd test
npm.cmd start
```

Веб-просмотр: `npm.cmd run preview`. Web-сборка: `npm.cmd run build:online` после задания RELEASE_REPOSITORY=OWNER/REPO; удобнее использовать Actions. Обычный большой установщик: `npm.cmd run fetch:encoder`, затем `npm.cmd run dist:win`.

## Возможности

Музыка через Windows GSMTC для совместимых плееров; для мгновенных событий Spotify предусмотрен мост Spicetify в spotify-bridge/. Ctrl+Alt+Left/Right — предыдущий/следующий трек; Ctrl+Alt+Down — пауза / воспроизведение. Наличие данных/управления зависит от того, что сообщает плеер.

Запись: MP4, 360p–4K, 30–240 FPS, выбор битрейта и источника, системный звук, микрофон, шумоподавление/эхо/автогромкость. Alt+F9 — запись, Alt+Z — панель. H.264 при возможности сохраняется без повторного кодирования; иначе проверяются NVENC/AMF/QSV и программный резерв. Выбранные FPS не означают дорисовку недостающих кадров.

Мгновенный повтор: до 10 минут, ограничение размера либо без лимита; Alt+F10 сохраняет накопленный фрагмент. По умолчанию выключен; при включении использует ресурсы захвата. Обычная запись временно приостанавливает повтор.

Скриншоты с выбором области и качества, показом/скрытием островка, просмотром последних файлов. Быстрый запуск поддерживает выбор приложений из процессов, поиск и «Запустить всё». Видео и снимки используют оформление приложения.

Файловые операции отображаются в островке с управлением; скрытие оригинального окна Проводника включается отдельной настройкой. Системное окно может кратко появляться при создании/закрытии: абсолютное отсутствие вспышки не гарантируется.

Ctrl+Alt+I скрывает/показывает островок. Настройки сохраняются в AppData, записи и снимки — в выбранных папках.

## Структура

- src/ — интерфейс;
- electron/ — интеграции, захват и хранение;
- native/ — Windows-медиасервис;
- distribution/ — маленький установщик/обновление и проверки;
- .github/workflows/release.yml — сборка и публикация;
- telegram-bot/ — бот и Docker Compose;
- tests/ — проверки приложения.
