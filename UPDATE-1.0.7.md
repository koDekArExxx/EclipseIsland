# EclipseIsland 1.0.7 — управление после скриншота

Восстановление ввода теперь выполняется после полного завершения захвата: сохранения, отмены выделения и ошибки. Состояние занятости сбрасывается до восстановления. Сбой уведомления больше не пропускает восстановление.

Сбрасываются прерванный захват указателя, перемотка, удержание и временные состояния кнопок. Для поздних оконных сообщений добавлен один отложенный повтор восстановления; первый дошедший клик отменяет его. Скрытый пользователем островок не появляется сам. Постоянного опроса или нового фонового таймера нет.

## Выпуск

Архив содержит накопленные изменения приложения 1.0.2–1.0.7. Распакуйте поверх исходников с заменой файлов. Это исходники: Windows Setup создаётся при выпуске через бота.

```powershell
git add .
git commit -m "EclipseIsland 1.0.7"
git pull --rebase origin main
git push origin main
```

После успешного push: бот → Выпустить обновление → `1.0.7`.

## Проверка

202 JavaScript-теста прошли, без ошибок и пропусков. Проверены завершение захвата, отмена и ошибка выделения, исключение уведомления, ограниченный повтор восстановления, отмена по актуальному подтверждению ввода, игнорирование старого подтверждения, сохранение скрытого состояния и очистка прерванных состояний указателя.

Настоящие Windows HWND и системный PrintScreen здесь не проверялись. Исправление относится к потоку снимков EclipseIsland и восстановлению его островка; нового перехвата системной клавиши PrintScreen нет. Перед массовым выпуском на Windows повторите снимок области, отмену Esc, снимок экрана, открытие/закрытие просмотра и клики после каждого действия. Отдельно проверьте системные «Ножницы»/PrintScreen и скрытие Ctrl+Alt+I.
