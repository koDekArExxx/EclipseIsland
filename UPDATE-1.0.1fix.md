# Выпуск 1.0.1 Fix

Внутренний номер приложения и тег обновления — **1.0.1**. Название релиза в GitHub — EclipseIsland 1.0.1 Fix. В боте/Actions вводи 1.0.1, без букв fix.

1. В папке своих исходников 1.0.0 выполни `git pull --rebase origin main`. Если Git пишет CONFLICT — сначала закончи объединение, не используй force push.
2. Распакуй содержимое EclipseIsland-1.0.1fix-update.zip поверх проекта с заменой файлов. package.json должен остаться прямо в корне.
3. Выполни:

```powershell
git add .
git commit -m "EclipseIsland 1.0.1 Fix"
git push
```

4. Выпусти 1.0.1 через /admin бота либо Actions → Publish EclipseIsland → Run workflow → main → версия 1.0.1. Нужен новый запуск по main.
5. После зелёной сборки скачай новый EclipseIsland-Setup.exe из Releases и закрой старый загрузчик перед его запуском. У пользователей, обновивших само приложение до 1.0.1, новый загрузчик также будет установлен приложением для следующего запуска.

Не проверяй новый загрузчик обычным запуском до публикации 1.0.1: старое приложение 1.0.0 может вернуть свой старый загрузчик. Для безопасного осмотра интерфейса без установки у загрузчика есть аргумент --preview.

В Actions внизу страницы запуска будет артефакт installer-ui-check с PNG проверочного интерфейса, если Windows-раннер предоставляет интерактивный рабочий стол. Сами DWM-углы и тень нужно оценивать в живом окне, а не через DrawToBitmap.

На Bothost архив не загружай: бот ради этого фикса не менялся.
