# EclipseIsland 1.0.2

- Добавлены режимы нагрузки: «Баланс», «Экономный», «Все эффекты».
- В экономном режиме отключаются постоянные анимации, blur и свечение островка. Цвета и управление сохраняются.
- В режиме «Баланс» эквалайзер свёрнутого островка не анимируется постоянно; при наведении оживает.
- Убраны глобальные отключения фонового ограничения Chromium; скрытое окно настроек больше не поддерживает активную отрисовку.
- Скрытые окна не получают потоки обновлений погоды, загрузок и инструментов; при открытии получают актуальный снимок.
- Добавлены профили записи: 720p/30, 1080p/60, 1440p/60.
- Автоматический битрейт зависит от фактического размера и частоты источника. Доступен ручной режим. Старые нестандартные значения битрейта сохраняются как ручные.
- При доступном MediaCapabilities учитывается энергоэффективность кодеков. Если API не отвечает или недоступен, используется совместимый резервный выбор.
- Масштабирование через canvas ограничено выбранной частотой, даже если источник присылает кадры чаще.
- Следующий сегмент повтора запускается до завершения файловых операций предыдущего. Запись блоков сохраняет порядок. Исправлена остановка во время смены сегмента.

## Как выпустить

Это архив изменённых исходников для проекта 1.0.1 Fix. Распакуйте его поверх своей папки EclipseIsland / DildoIsland с заменой файлов. Бот не изменяется.

В PowerShell из папки проекта:

```powershell
git add .
git commit -m "EclipseIsland 1.0.2"
git pull --rebase origin main
git push origin main
```

На GitHub: Actions → Publish EclipseIsland → Run workflow → version: `1.0.2` → Run workflow.
Дождитесь зелёного запуска и релиза `v1.0.2`. Сборка сформирует маленький Setup и новый payload с манифестом. Готовый Windows EXE в этот архив не входит.

## Проверка на Windows перед публикацией

Проверьте игру с островком / без островка, затем отдельно с включённым повтором. Для слабого ПК: Обзор → Нагрузка на ПК → Экономный; Запись → профиль Экономный; повтор 720p/30. При тяжёлой игре оставьте запас GPU: полностью загруженная видеокарта может не успевать захватывать кадры даже с аппаратным кодировщиком.
Проверьте обычную запись и повтор со звуком, паузу/продолжение, остановку во время сохранения повтора, просмотр MP4 и переключение Ctrl+Alt+I. Проверьте H.264 на NVIDIA/AMD/Intel и резервный кодек на машине без доступного аппаратного кодирования.
Из этой среды не проверялись игровой FPS, Windows-захват и фактическое использование NVENC/AMF/Quick Sync. MediaRecorder не даёт гарантированно выбрать конкретный аппаратный кодировщик.
