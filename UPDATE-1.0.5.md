# EclipseIsland 1.0.5

- Источник погодных данных заменён на wttr.in. API-ключи и регистрация не нужны.
- Запросы идут по координатам выбранного города; основной домен ru.wttr.in, резервный — wttr.in. Домены принадлежат одному сервису, это не два независимых провайдера.
- В Windows используется сетевой стек Electron/Chromium с системными сетевыми настройками.
- Встроен справочник 1117 российских городов. Они ищутся без сети, включая «СПБ», «Питер», «Санкт Петербург» и «Moscow». Если локального совпадения нет, сохранён международный онлайн-поиск через геокодер Open-Meteo; погодный прогноз с Open-Meteo больше не запрашивается.
- Добавлены кэш на 10 минут, объединение одновременных запросов и ограничение частоты ручного обновления. При временном сбое можно показать последние данные того же города возрастом до 6 часов с явной отметкой «Сохранённые данные». Кэш хранится в памяти текущего запуска, после перезапуска не восстанавливается.
- В островке видны источник и ветер; время сохранённых данных не подменяется свежим. Иконка дня/ночи рассчитывается по координатам, а не часовому поясу ПК.
- Включены все исправления 1.0.2–1.0.4, в том числе восстановление кликов после просмотра записи.

## Как выпустить через бота

Распакуйте архив поверх исходников с заменой файлов. Это исходники обновления, Windows Setup собирается при выпуске. Бот не меняется.

В терминале VS Code из папки проекта:

```powershell
git add .
git commit -m "EclipseIsland 1.0.5"
git pull --rebase origin main
git push origin main
```

После успешной отправки: бот → Админка → Выпустить обновление → `1.0.5`.

Ролик находится в `test-results/release-video/EclipseIsland-1.0.5-weather.mp4`, папка исключена из Git. Около 15 секунд, 1080×1080, 60 FPS, музыка приглушена. Показаны только изменения погоды: новый источник, локальный поиск города, сохранённые данные при сбое. Использованы настоящие ответы сервиса для Москвы и Казани; сбой сети в ролике обозначен как пример.

## Проверки и ограничения

192 JavaScript-теста и 12 Python-тестов бота прошли. Проверены локальный поиск, кодирование международного запроса, разбор данных и единицы ветра, второй домен, объединение запросов, кэш и его срок, изоляция разных городов, ошибки, день/ночь и безопасная отрисовка текста.

Получены реальные ответы wttr.in для Москвы, Санкт-Петербурга и Казани. Проверка выполнена из среды разработки; это не проверка с IP всех российских провайдеров. Доступ без VPN зависит от DNS, провайдера и самого сервиса — гарантировать его для каждой сети нельзя. Перед массовым выпуском проверьте погоду без VPN на целевом ПК и смените город. Также проверьте открытие/закрытие видеоплеера и клики островка.
