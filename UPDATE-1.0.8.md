# EclipseIsland 1.0.8 — клики после обрезки

Предыдущий повтор включения mouse events не устранил проблему у пользователя. Вместо повторного использования того же нативного окна после выделения области теперь создаётся новое окно островка. Приложение, музыка, запись и буфер повтора не перезапускаются. Островок возвращается свёрнутым; настройки оформления и данные берутся из работающего основного процесса. Скрытый пользователем островок остаётся скрытым.

Выделение явно освобождает pointer capture до отправки результата. В основном процессе окно выделения перестаёт принимать ввод и фокус, скрывается и уничтожается; обработка снимка продолжается только после события closed. Если островок исключён из снимков, он остаётся скрытым всё время выделения. Обновление старых таймеров и диагностика старого окна удаляются. Защита от попадания в запись применяется к новому окну.

## Установка исходников и выпуск

Распакуйте архив поверх проекта с заменой файлов. Архив включает накопленные изменения 1.0.2–1.0.8 и ролик. Это исходники; Windows Setup собирается через бота.

```powershell
git add .
git commit -m "EclipseIsland 1.0.8"
git pull --rebase origin main
git push origin main
```

После успешного push: админка бота → Выпустить обновление → `1.0.8`.

## Проверено

204 JavaScript-теста прошли, ошибок и пропусков нет. Проверены отложенное закрытие нативного окна, отсутствие преждевременного восстановления, отмена, ошибка загрузки выделения, освобождение указателя до finish IPC, пересоздание только островка без повторного запуска служб, данные после пересоздания и сохранение ручного скрытия. 15 браузерных проверок выделения прошли: разные размеры, темы, обратное выделение, отмена.

Реальные Windows HWND и маршрутизация мыши после системного захвата здесь недоступны. После сборки проверьте на Windows: многократную обрезку с кликами по вкладкам, отмену Esc во время выделения, захват во время записи, скрытие Ctrl+Alt+I и повторные снимки. Результат этих проверок пока не подтверждён.

Ролик содержит только основные изменения в действии, общая подпись — 1.0.8. Это браузерная демонстрация с тестовыми данными, не подтверждение исправления Windows-ввода.
