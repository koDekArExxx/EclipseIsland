- Маленький web Setup и обновления перед запуском через GitHub Releases.

- FFmpeg загружается один раз по необходимости с SHA-256; исключён из web-пакета.
- Сохранены функции и оформление исходной 0.8.2.

## 0.8.2 — original FPS and smooth settings corners
- Восстановлен счётчик FPS первого билда; удалены PresentMon и запросы разрешений. Это FPS островка.

## 0.8.2 — резервный FPS без повышения прав
- Автоматический выбор настоящих кадров приложения или явно подписанного FPS UI; выбор источника в обзоре.

- Ошибка скачивания дополнительного компонента больше не блокирует сборку.

## 0.8.2 — встроенный FPS и звуки завершения

## 0.8.2

- Адаптивная высота раскрытых вкладок с плавным изменением нижней рамки, прокруткой длинных списков и сохранением рамки при увеличенном масштабе.

- Добавлен переключатель «Показывать курсор мыши» для скриншотов области и экрана. Windows-захват включает указатель только при включённой настройке, не скрывая его на рабочем столе.

- Глобальные музыкальные сочетания: Ctrl+Alt+← / → — предыдущий / следующий трек, Ctrl+Alt+↓ — пауза. Добавлены на страницу «Горячие клавиши».
- Встроенный видеоплеер получил собственные кнопки воспроизведения, перемотки, громкости, скорости, разворота окна и полного экрана. Разворот/полный экран управляют только доверенным окном просмотра через IPC и не зависят от запрета HTML fullscreen в основной сессии.
- Ползунок не спорит с обновлением позиции: предпросмотр времени во время перетаскивания, один seek при отпускании, сохранение паузы и защита от устаревших play-promises. Перемотка в конец больше не перезапускает видео.
- Поток записей поддерживает HEAD, диапазоны и прерывание предыдущего запроса при новом seek; приватное кэширование разрешено для неизменяемого файла записи.
- Мгновенный повтор: отдельные микрофон, шумоподавление, эхо, автогромкость, усиление, системный звук, его громкость и аудиобитрейт. Старые общие настройки мигрируют один раз.
- Опциональные фильтр голоса ниже 80 Гц и компрессор после усиления применяются только к микрофону, системный звук остаётся отдельной веткой. Без эффектов сохраняется прямой аудиопуть. Предупреждения источника отображаются в статусе повтора.
- Изменения обычных аудионастроек больше не перезапускают буфер, если настройки звука повтора заданы отдельно.

## 0.8.1

- Исправлено восстановление островка после скриншота: временное скрытие проходит через общий контроллер видимости, не возвращает устаревшую нулевую прозрачность и учитывает Ctrl+Alt+I во время захвата.
- Снимки открываются во встроенном просмотре с масштабом 100%, копированием и открытием папки. Закрытие просмотра повторно восстанавливает положение, видимость и ввод островка, сохраняя пользовательское отключение.
- Быстрый запуск: поиск по названию/пути в островке и настройках, добавление из доступных процессов Windows, поиск по процессам и кнопка «Запустить всё» под сеткой. При ошибке одного ярлыка остальные продолжают запускаться; повторный пакет блокируется.
- Скриншоты: PNG / JPEG, качество JPEG 50–100%, исходный размер или ограничение высоты до 720/1080/1440/2160p без увеличения, выбор монитора, задержка 0/3/5/10 с отменой, скрытие островка и настроек, уведомление и автоматический просмотр.
- Выбор приложений из процессов использует только полученные от Windows пути EXE; одинаковые процессы объединяются. Доступ к защищённым системным процессам не запрашивается.

## 0.8.0

- Быстрый запуск: вкладка «Пуск» в островке и отдельная страница настроек. До 24 выбранных приложений EXE / ярлыков LNK / папок, иконки приложений, переименование, порядок и удаление закреплений. Ctrl+Alt+L открывает вкладку.

До 24 последних снимков с просмотром, повторным копированием и открытием папки. JPEG используется только для небольших миниатюр и фона выделения.
- Выделение области в отдельном окне: перетаскивание в любом направлении, Esc / правая кнопка / потеря фокуса для отмены. Координаты пересчитываются по реальному размеру кадра, в том числе при масштабировании монитора. Островок и настройки временно исключаются из кадра, прозрачность восстанавливается при ошибке.
- Захват выполняется по запросу, фонового опроса экрана нет. Использован актуальный ClipboardItem / Blob API Electron 45.

## 0.5.5

- Запрос снимка Spotify инициируется островком раз в секунду, независимо от фоновых таймеров Spotify. WebSocket pong больше не является единственным признаком работоспособности передачи данных.
- Повторяющееся кэшированное значение позиции не обнуляет локальный отсчёт. Событийный isPaused/isPlaying учитывается до устаревшего getter.
- Загрузка обложек использует Chromium net.fetch с системными настройками прокси. Сначала выбирается обычная обложка, а не максимальная; загрузка ограничена 8 MB с обработкой в миниатюру.
- Неудачная загрузка изображения повторяется с ограниченным числом попыток; смена трека или остановка отменяет старую попытку.
- Диагностика содержит версию реально загруженного расширения, ошибку запроса снимка, число попыток загрузки и безопасный код ошибки изображения.
- Установщик сначала применяет существующую резервную копию и при необходимости пробует backup apply. Ошибка содержит конкретную команду и последние строки вывода с удалением ключей, вместо одного exit 1.
- Ошибка установки из отчёта 0.5.4 не установлена достоверно без журнала; автоматические проверки не заменяют проверку Spicetify на Windows.

- Новая обложка запрашивается и при запоздалом появлении URL. Название не ждёт загрузки изображения.
- При смене трека или плеера интерфейс сбрасывает старую длительность и позицию, пока новые сведения не получены. Смена трека завершает удержание ползунка.
- В диагностику прямого моста добавлены наличие обложки, её состояние, позиция и длительность без URL или приватных ключей.

# EclipseIsland 0.5.0

- Добавлен прямой локальный мост Spotify через расширение Spicetify. Смена трека берётся из события songchange самого Spotify, а не из задержанной Windows Media Session.
- Расширение передаёт название, исполнителя, реальный адрес обложки, длительность, позицию и состояние воспроизведения. Обложка загружается из кэша браузера Spotify, если это возможно; резервная загрузка ограничена оригинальными Spotify CDN и не задерживает название.

- Прямые данные имеют приоритет для Spotify; старые сообщения Windows не откатывают трек. Ручной выбор другого источника сохраняет управление через Windows. Остальные плееры продолжают использовать системный мост.

- Добавлено чтение `Thumbnail` текущей медиасессии Windows. Обложка отображается в мини-острове, виджете и большом плеере; поддерживаются PNG, JPEG, GIF, WebP и BMP до 2 MiB. Тип определяется по байтам, даже если плеер не передал MIME.
- Изображения уменьшаются до 320 px, кэшируются, передаются отдельно от позиции трека. Поздняя обложка предыдущего трека отбрасывается. Если плеер не передаёт изображение, остаётся оформление с иконкой.
- Настройки 0.1 подхватываются автоматически. Новые значения дополняются без сброса выбранного города и старых опций.
- 18 автоматических тестов. Реальные WinRT-сессии, Acrylic и поведение CS требуют проверки на Windows.

## Как обновиться

1. Закройте старый Island через значок в трее → «Выйти из Island».
2. Скопируйте содержимое папки `island-pc` из нового архива в свою папку проекта, например `DildoIsland`, с заменой файлов. Уже установленную папку `node_modules` удалять не требуется.
3. Откройте терминал в этой папке и запустите `npm.cmd start`. Если зависимости ещё не установлены: сначала `npm.cmd ci`.

Настройки оформления находятся в разделе «Внешний вид». Чтобы оценить интерфейс без запуска, откройте `Island-preview.html`.

### FPS: устойчивое подключение и диагностика
- PresentMon принимает кадры связанных процессов одного приложения (включая GPU-процесс браузера), не подменяя FPS частотой обновления экрана.
- Встроенная сессия восстанавливается после аварийного завершения; отключён ненужный сбор GPU/input/display telemetry для счётчика кадров.
- В разделе «Обзор → Источник FPS» видна причина отсутствия данных; диагностика копируется кнопкой, журнал сохраняется в fps-diagnostics.json в каталоге настроек.
- Сборка Setup по-прежнему автоматически включает проверенный PresentMon. На Windows для ETW могут потребоваться права администратора или членство в Performance Log Users. При отсутствии кадров отображается прочерк.
