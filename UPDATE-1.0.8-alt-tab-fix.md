# EclipseIsland 1.0.8 — пустые карточки Alt + Tab

На пользовательском снимке в Alt + Tab видны нормальное окно настроек и две пустые карточки EclipseIsland. Фоновое окно захвата имеет заголовок «EclipseIsland — запись», островок — «EclipseIsland». По одному изображению нельзя однозначно установить HWND каждой карточки; исправление применено ко всем соответствующим служебным поверхностям.

Островок, работник записи, работник повтора и временное окно выделения теперь создаются с общими параметрами служебного окна. На Windows используется поддерживаемый Electron тип toolbar, который выставляет WS_EX_TOOLWINDOW, дополнительно к skipTaskbar. Работники записи/повтора не получают фокус. Выделение сохраняет возможность принимать клавиатуру для Escape. Настройки, просмотр видео и фото остаются обычными окнами. Повторное создание островка после Ctrl + Alt + I и обрезки тоже использует новый тип.

Источники:
- https://www.electronjs.org/docs/latest/api/structures/base-window-options
- https://github.com/electron/electron/blob/main/shell/browser/native_window_views.cc

Версия осталась 1.0.8. Архив включает исправления обрезки, возврата через Ctrl + Alt + I, package-lock и флажок перевыпуска.

## Выпуск

Распакуйте поверх проекта с заменой файлов.

```powershell
git add .
git commit -m "Fix 1.0.8 empty Alt Tab windows"
git pull --rebase origin main
git push origin main
```

Затем GitHub → Actions → Publish EclipseIsland → Run workflow → 1.0.8 → replace_existing. Дождитесь успешной сборки. Для старой установленной 1.0.8 нужна переустановка из нового Setup после штатного удаления приложения; одинаковый номер загрузчик не обновляет. Подробности — UPDATE-1.0.8-hide-fix.md.

## Проверено

205 JS-тестов прошли, без ошибок и пропусков. Проверены Windows toolbar-параметры и клавиатура выделения, параметры работников захвата/повтора, обычный тип настроек, повторные циклы создания островка и отсутствие перезапуска служб.

Настоящий Alt + Tab и нативная мышь Windows в этой среде не проверены. На Windows проверьте: запуск с включённым повтором, Alt + Tab, Ctrl + Alt + I несколько раз, снимок области с Esc, запись и открытие её просмотра. В переключателе должны остаться только открытые пользовательские окна (настройки/просмотры), без служебных карточек. Для проверки клавиатуры поиска в островке дополнительно откройте быстрый запуск и введите запрос.
